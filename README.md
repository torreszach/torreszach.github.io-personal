# Zach Torres — Personal Contact Site

Personal GitHub Pages contact card for NFC use.

Includes phone, Discord, Steam, Instagram, LinkedIn, Denver location, the supplied logo, and a downloadable vCard with the logo embedded as the contact image. There is no Date Met field.

## Publish
Upload the contents of this folder to a GitHub repository so `index.html` is at the root. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/(root)`.

Once live, write the final HTTPS GitHub Pages URL to your NFC tag.

> Note: Information on a public GitHub Pages site is publicly accessible.
